## Installation

### NPM
Installing Zener using NPM (Node Package Manager).

```sh
npm i @sugbosuite/zener
```

### CDN
Using Zener through a CDN (Content Delivery Network).

```sh
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/sugbosuite/zener@147f9aa9940eb2afc4435187ae3d8958da3bcc9d/zener.css" integrity="sha256-MEBrbXijmk/ncHToGUdky7BnoMROW+pBsIHA22mcoaM=" crossorigin="anonymous" fetchpriority="high">
```
